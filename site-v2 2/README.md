# transform-with.ai

Static site for GitHub Pages. No JavaScript, no cookies, no third-party requests.

Before publishing: replace [COMPANY NUMBER] in the footer of index.html.

Files: index.html, 404.html, CNAME, .nojekyll, favicon.svg, og.png (social preview), robots.txt, sitemap.xml.

Edit HTML only in a code editor (VS Code, nano). TextEdit rewrites the file and breaks it.
